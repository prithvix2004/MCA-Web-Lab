JavaScript Predefined Objects

1. String Object Methods

Method Description Result Output
.length (Property) Returns the total number of characters. -
.toUpperCase() Converts all characters to uppercase. -
.toLowerCase() Converts all characters to lowercase. -
.charAt(7) Returns the character at index 7. -
.indexOf('Java') Returns the starting index of the word 'Java'. -
.slice(7, 17) Extracts a section from index 7 up to 17. -
.replace('World', 'Universe') Replaces 'World' with 'Universe'. -

2. Math Object Methods

Method Description Result Output
Math.abs(x) Returns the absolute (positive) value. -
Math.ceil(x) Rounds the number UP to the nearest integer. -
Math.floor(x) Rounds the number DOWN to the nearest integer. -
Math.round(x) Rounds to the nearest integer. -
Math.sqrt(Math.abs(x)) Returns the square root of the absolute value. -
Math.pow(x, 2) Squares the entered number (x squared). -
Math.random() Generates a random decimal between 0 (inclusive) and 1 (exclusive). -
